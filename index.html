업무별 표준 프롬프트 템플릿 배포

임직원이 기밀 정보를 직접 입력하지 않고도 안전하게 결과를 얻을 수 있는 검증된 표준 프롬프트 양식을 배포하고 우수사례를 전파합니다.

관점 분류 사용자/프로세스
핵심 레퍼런스 만다라트 #7 / 8관점

1. Quick Wins (최우선 즉시 실행)

Phase 1

비용과 기술 장벽은 낮으면서 보안 사고 예방 효과가 즉각적인 과제. 가이드라인 공지, 데이터 3단계 분류 수칙, 표준 프롬프트 배포, 기업용 엔터프라이즈 계정(학습 미사용 옵션) 도입.

2. Major Projects (전략적 투자)

Phase 2

구축 예산과 시간이 소요되나 근본적인 보안 체계를 완성하는 과제. AI 전용 실시간 모니터링/DLP 필터링, 안전한 API 게이트웨이, 중요 업무용 폐쇄형 sLLM(구축형) 도입.

3. Fill-ins (단기 보완/일상화)

상시 운영

큰 리소스 없이 점진적 보안 태세를 다지는 일상적 관리 과제. 불필요 라이선스 회수, 타 기관 보안 사례 벤치마킹, 접속 로그 주기적 점검, 사내 질의 채널 운영.

4. Thankless / Re-evaluate (재검토·지양)

지양/대체

실행 난이도는 극도로 높으나 생산성을 심각하게 저해하거나 실효성이 떨어지는 방식. 전면적인 상용 AI 사용 금지, 모든 프롬프트 건별 다단계 사전 결재제, 벤더 소스코드 전수 검증 요구.
